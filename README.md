# Portfolio Vinicius Vecchiotti

Meu portfólio pessoal construído do zero para centralizar meus projetos e estudos na área de dados. 

Atualmente, sou estudante de Ciência da Computação na Universidade Federal do ABC (UFABC) e estou focado em me desenvolver como Analista de Dados. 

## Tecnologias

O site foi feito sem frameworks para garantir a melhor performance e controle sobre as animações:
* **HTML & CSS:** Estrutura responsiva utilizando Bento Grid e variáveis nativas para o sistema de Dark/Light mode.
* **JavaScript (Vanilla):** Lógica de troca de temas e manipulação da DOM.
* **HTML5 Canvas:** Utilizado para criar as animações do fundo (quebras geométricas) e do card principal (rede de dados interativa com física de atração do mouse).

## Estrutura do Site

* **Análise Olist:** Destaque para o meu projeto de logística e satisfação do cliente.
* **Portfólio 3D & Arte:** Site desenvolvido para exibir projetos de design e modelagem 3D.
* **Contato:** Sistema de proteção de e-mail contra web scrapers via JS.
